# Evaluacion2 - Software de Geolocalización con Graphhopper

Este proyecto es una aplicación interactiva en Python que consume la API de Graphhopper para realizar geocodificación de ubicaciones y cálculo de rutas punto a punto.

## Funcionalidades
- Interfaz completamente traducida al español.
- Formateo de distancias e indicaciones con un máximo de 2 decimales.
- Búsqueda con perfiles de vehículo (car, bike, foot).
- Narrativa de viaje e indicaciones paso a paso en español.
- Opción de salida del programa mediante "s" o "salir".

## Requisitos
- Python 3
- Librería `requests`
- API Key activa de Graphhopper
